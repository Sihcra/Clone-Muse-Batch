    API key
    Bắt buộc với API v1. Gửi qua header Authorization: Bearer <key>. Đổi key thì key cũ hết dùng.
    
          
    
            
            
            
            
            
          
    
          
    
        
    

        
    
          
    Tài liệu API v1
    Tạo task trả về ngay {task:{id,status:"queued"}}; hỏi lại theo id tới khi succeeded rồi tải file.
    
          
    POST   /api/v1/tasks               tạo task
       {"prompt": "...", "images": [{"imageUrl": "https://..."} | {"imageBase64": "data:image/jpeg;base64,..."}],
        "timeoutMin": 10, "label": "tên gợi nhớ", "kind": "video|image", "expect": 1, "ratio": "9:16"}
GET    /api/v1/tasks?status=&limit=   danh sách (status: queued|processing|succeeded|failed|cancelled)
GET    /api/v1/tasks/:id           xem 1 task
POST   /api/v1/tasks/:id/cancel    huỷ
POST   /api/v1/tasks/:id/retry     chạy lại task lỗi / đã huỷ
DELETE /api/v1/tasks/:id           xoá
GET    /api/v1/tasks/:id/file?i=0  tải file kết quả (mp4 hoặc ảnh)
